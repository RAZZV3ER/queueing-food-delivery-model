# Queueing Models for Food Delivery Platform Logistics

## Overview
This project analyzes food delivery systems using queueing theory (M/M/1 model). It focuses on waiting time, queue length, and system performance.

## Methodology
- Modeled system using M/M/1 queue
- Defined arrival rate (λ) and service rate (μ)
- Calculated performance metrics:
  - Waiting Time (W)
  - Queue Length (L)
  - Utilization (ρ)
- Generated graphs using Python
- Simulated real-time queue behavior

## Results
- Waiting time increases as arrival rate approaches service rate
- Queue length grows rapidly under high demand
- Simulation shows system overload when λ > μ

## Graphs
Include:
- Waiting Time vs Arrival Rate
- Queue Length vs Arrival Rate
- Queue Simulation Over Time

## Real-World Application
Used in food delivery platforms like Swiggy and Zomato to optimize delivery efficiency.

## Conclusion
Queueing theory helps improve system performance by balancing demand and service capacity.
